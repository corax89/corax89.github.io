загрузка ядра… — к/с — 0
При загрузке страницы автоматически запускается тестовый мидлет M3GTest (JSR-184, вращающийся куб). Чтобы запустить свою игру — кнопка «Загрузить свой мидлет». Рекорды и сохранения (RMS) хранятся в браузере.
Страница не изолирована (cross-origin isolation отсутствует). Ядру нужны настоящие потоки (SharedArrayBuffer), которые браузер даёт только изолированным страницам. Откройте сайт в Chrome / Edge / Firefox, локально: python3 serve_web.py, или хостинг с COOP/COEP (Netlify / Cloudflare Pages / Vercel).
Параметры (действуют при следующем запуске)

Нажмите «Применить» — мидлет перезапустится с новыми параметрами. Масштаб меняется на лету и перезапуска не требует.
