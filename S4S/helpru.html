Игра

Управление

Проверить нажатие клавиши
Возвращает true, если указанная клавиша нажата в текущий момент. Поддерживает стрелки и кнопки A/B/X/Y. Можно использовать для непрерывного движения при удерживании клавиши.
Проверить нажатие клавиши (один раз)
Возвращает true только в момент первого нажатия клавиши, а не при удерживании. Идеально для одиночных действий типа прыжка или выстрела.
Получить значение оси джойстика
Возвращает значение (-1.0 до 1.0) указанной оси контроллера (0-3). Оси 0 и 1 - обычно левый стик, 2 и 3 - правый стик.
Вибрация
Активирует вибрацию на поддерживаемых устройствах. Можно настроить как простую вибрацию (указав длительность), так и сложные паттерны.

Таймеры

Установить интервал
Выполняет указанный код через заданные промежутки времени (в миллисекундах). Возвращает ID интервала, который можно использовать для его остановки.
Очистить интервал
Останавливает выполнение интервала по его ID. Важно очищать интервалы, когда они больше не нужны, чтобы избежать утечек памяти.
Установить таймер
Выполняет код однократно через указанное время (в миллисекундах). Полезен для задержек и отложенных действий.

Звук и музыка

Редактор музыки
Визуальный редактор для создания музыкальных последовательностей. Позволяет комбинировать ноты разных длительностей и высот.
Воспроизвести музыку
Проигрывает музыку, созданную в редакторе, с указанным темпом (BPM). Можно использовать для фоновой музыки и звуковых эффектов.
Редактор звука
Генератор звуковых волн для создания простых звуковых эффектов. Поддерживает разные формы волны (синус, квадрат, пила).
Воспроизвести звук
Проигрывает звук, созданный в редакторе. Оптимизирован для коротких звуков (выстрелы, прыжки, сбор предметов).

Работа с данными

Сохранить переменные
Сохраняет текущие значения указанных переменных в локальное хранилище браузера. Данные сохраняются между сессиями.
Загрузить переменные
Восстанавливает значения переменных из локального хранилища. Автоматически определяет типы сохраненных данных.
Многострочный ввод JS
Позволяет вставлять чистый JavaScript код для сложной логики, которую невозможно выразить блоками. Поддерживает ES5 синтаксис.
Игровой цикл
Основной цикл игры, который выполняется каждый кадр. Содержит логику обновления состояния игры и рендеринга.
Пауза/Продолжить
Приостанавливает или возобновляет выполнение игры. Можно использовать для создания меню паузы.
Проверить паузу
Возвращает true, если игра находится в состоянии паузы.
Установить фон
Задает фоновое изображение для игры. Можно выбрать режим отображения: растянуть или замостить.
Установить позицию фона
Задает смещение фонового изображения по осям X и Y.

Объекты

Создание объектов

Новый прототип объекта
Создает шаблон (класс) для объектов с заданными параметрами (размер, спрайт). Прототипы позволяют создавать множество однотипных объектов.
Новый объект
Создает экземпляр объекта с указанными координатами, размерами и спрайтом. Можно добавить код инициализации в событие onCreate.
Новый объект из прототипа
Создает объект на основе ранее определенного прототипа, копируя все его свойства. Экономит время при создании однотипных объектов.
Клонировать объект
Создает точную копию существующего объекта со всеми текущими значениями свойств. Полезно для спавна врагов или создания копий.
Копировать состояние
Копирует все свойства (кроме позиции) из одного объекта в другой. Можно использовать для сброса состояния или синхронизации объектов.

Управление объектами

Изменить параметр объекта
Устанавливает новое значение для указанного свойства объекта (x, y, скорость, видимость и др.). Поддерживает разные типы объектов.
Добавить к параметру
Увеличивает (или уменьшает) значение свойства объекта на указанную величину. Удобно для постепенного изменения скорости, размера и т.д.
Получить параметр объекта
Возвращает текущее значение свойства объекта. Можно использовать для проверки состояния или математических расчетов.
Удалить объект
Полностью удаляет объект из игры, освобождая ресурсы. Важно удалять ненужные объекты для оптимизации производительности.
Итерировать объекты
Выполняет указанный код для каждого объекта в игре. Можно фильтровать объекты по имени или другим свойствам внутри цикла.
Получить объект
Возвращает ссылку на объект по его типу (текущий, столкнувшийся, случайный и т.д.).
Установить границы столкновений
Настраивает форму и размеры области столкновений для объекта (прямоугольник, круг или автоматический расчет).

События объектов

При каждом кадре
Код выполняется каждый игровой цикл (обычно 60 раз в секунду). Идеально для непрерывного движения и проверок.
При столкновении
Код выполняется при столкновении объекта с другим объектом. Внутри блока доступна переменная 'object' - ссылка на второй объект.
Анимация объекта
Настраивает анимацию спрайтов для объекта: список кадров, скорость проигрывания и зацикливание.
Редактор спрайтов
Визуальный редактор для создания и редактирования спрайтов объектов.
↑ Наверх

Движение

Физика

Установить гравитацию
Задает силу гравитации, действующую на все объекты в игре. Положительные значения тянут вниз, отрицательные - вверх.
Управление объектом
Настраивает управление объектом с клавиатуры или геймпада. Поддерживает несколько схем управления (платформер, top-down shooter).

Перемещение

Задать скорость
Устанавливает скорость движения объекта по осям X и Y. Можно использовать для импульсного движения или резкой смены направления.
Телепортировать
Мгновенно перемещает объект в указанные координаты или к другому объекту. Не учитывает коллизии при перемещении.
Движение к точке
Плавно перемещает объект к указанным координатам с заданной скоростью.
Расстояние до точки
Вычисляет расстояние между двумя объектами или между объектом и точкой. Возвращает значение в пикселях.
Камера следует за
Заставляет игровую камеру плавно следовать за указанным объектом. Можно настроить плавность и смещение камеры.

Позиционирование

Получить позицию окна
Возвращает текущие координаты игровой камеры (видимой области). Полезно для UI элементов и проверки видимости объектов.
Установить позицию экрана
Перемещает игровую камеру в указанные координаты. Можно использовать для кат-сцен или статических камер.
Проверить столкновение
Проверяет пересечение двух прямоугольных областей. Возвращает true, если области пересекаются. Не учитывает вращение.
↑ Наверх

Логика

Условия

Если-иначе
Стандартное условное выражение. Выполняет код в зависимости от истинности условия. Можно добавлять любое количество веток "иначе если".
Сравнение
Сравнивает два значения с выбранным оператором (==, !=, >, <, >=, <=). Возвращает true или false.
Логические операции
Выполняет логические И/ИЛИ между двумя условиями. Полезно для комплексных проверок.
Отрицание
Инвертирует логическое значение (true становится false и наоборот). Удобно для проверки "если не выполняется условие".
Проверка имени объекта
Сравнивает имя объекта со строкой. Полезно для фильтрации столкновений между определенными типами объектов.

Специальные проверки

Объект за экраном
Проверяет, полностью ли объект вышел за границы игрового экрана. Можно использовать для удаления пуль или спавна врагов.
Касание объекта
Проверяет, коснулся ли игрок указанного объекта (тап/клик). Учитывает поворот и масштаб объекта.
Столкновение с тайлом
Проверяет, сталкивается ли объект с тайлом определенного типа. Полезно для определения "опасных" или "проходимых" тайлов.
Получить информацию о тайле
Возвращает информацию о тайле, с которым столкнулся объект (координаты, ID и другие параметры).
↑ Наверх

Циклы

Основные циклы

Повторить
Выполняет код указанное количество раз. Можно задать точное число повторений или использовать переменную.
Пока
Выполняет код, пока условие истинно. Важно убедиться, что условие когда-нибудь станет ложным, иначе цикл будет бесконечным.
Цикл for
Классический цикл со счетчиком. Позволяет задать начальное значение, конечное условие и шаг изменения счетчика.
Для каждого
Перебирает все элементы списка. Внутри цикла доступна переменная с текущим элементом списка.

Управление циклами

Прервать
Немедленно выходит из текущего цикла, даже если условие продолжения еще истинно. Полезно при поиске элемента в списке.
Продолжить
Пропускает текущую итерацию цикла и переходит к следующей. Удобно для фильтрации элементов в цикле.
↑ Наверх

Математика

Основные операции

Число
Числовая константа. Можно ввести целое или дробное число, в том числе отрицательное.
Арифметика
Выполняет базовые арифметические операции: сложение, вычитание, умножение, деление и возведение в степень.
Округление
Округляет число по выбранному правилу: вверх, вниз, до ближайшего целого или просто отбрасывает дробную часть.
Модуль
Возвращает остаток от деления одного числа на другое. Полезен для создания циклических эффектов и ограничения значений.
Случайное число
Генерирует случайное число в указанном диапазоне. Может возвращать как целые, так и дробные значения.

Тригонометрия

Sin/Cos/Tan
Тригонометрические функции. Принимают угол в градусах. Полезны для кругового движения и колебательных эффектов.
Константы
Основные математические константы: π (пи), e (основание натурального логарифма), √2, φ (золотое сечение) и другие.

Ограничения

Ограничить диапазон
Гарантирует, что значение останется между указанными минимумом и максимумом. Если значение выходит за границы, оно приравнивается к ближайшей границе.
Свойства числа
Проверяет различные свойства числа: четность, положительность, конечность (не NaN и не Infinity), делимость на другое число.
↑ Наверх

Текст

Работа со строками

Текст
Строковая константа. Можно ввести любой текст, включая пробелы и специальные символы.
Объединить
Соединяет несколько строк в одну. Можно указать любое количество элементов и разделитель между ними.
Длина
Возвращает количество символов в строке. Для пустой строки возвращает 0.
Пустая строка?
Проверяет, является ли строка пустой (не содержит ни одного символа, даже пробелов).
Изменение регистра
Преобразует строку в верхний или нижний регистр. Учитывает локаль для специальных символов.

Поиск и извлечение

Найти позицию
Ищет подстроку в строке и возвращает позицию первого совпадения (начиная с 0). Если подстрока не найдена, возвращает -1.
Символ по индексу
Возвращает символ, находящийся на указанной позиции в строке. Позиции нумеруются с 0.
Подстрока
Извлекает часть строки между указанными позициями. Можно задать только начальную позицию, тогда вернется строка до конца.
Обрезать пробелы
Удаляет пробелы и другие whitespace-символы с начала и конца строки. Не изменяет пробелы внутри строки.

Вывод

Вывести текст
Отображает текст на игровом экране в указанных координатах. Можно задать размер, цвет и сам текст.
Запросить ввод
Показывает диалоговое окно с запросом ввода текста от пользователя. Возвращает введенную строку.
↑ Наверх

Списки

Создание списков

Пустой список
Создает новый пустой массив. Можно использовать для последующего заполнения элементами.
Создать список
Создает список с указанными элементами. Можно добавить любое количество элементов разных типов.
Повторить элемент
Создает список, заполненный одним и тем же элементом указанное количество раз. Полезно для инициализации массивов.

Операции со списками

Длина списка
Возвращает количество элементов в списке. Для пустого списка возвращает 0.
Пустой список?
Проверяет, содержит ли список хотя бы один элемент. Возвращает true, если список пуст.
Найти позицию
Ищет элемент в списке и возвращает его индекс (начиная с 0). Если элемент не найден, возвращает -1.
Получить элемент
Возвращает элемент списка по указанному индексу. Можно получить элемент с конца, используя отрицательные индексы.
Установить элемент
Заменяет элемент списка на указанной позиции новым значением. Можно использовать отрицательные индексы для отсчета с конца.
Подсписок
Извлекает часть списка между указанными индексами. Можно задать только начальный индекс, тогда вернется список до конца.

Модификация списков

Разделить строку
Разбивает строку на список подстрок, используя указанный разделитель. Если разделитель не указан, разбивает по символам.
Добавить элемент
Добавляет новый элемент в конец списка. Эквивалент метода push() в JavaScript.
Удалить последний
Удаляет и возвращает последний элемент списка. Эквивалент метода pop() в JavaScript.
↑ Наверх

Рисование

Примитивы

Цвет
Палитра для выбора цвета с предустановленными вариантами. Возвращает строку с hex-кодом цвета (#RRGGBB).
Точка
Рисует точку (пиксель) указанного цвета в заданных координатах. Можно использовать для создания простых изображений.
Линия
Рисует линию между двумя точками с указанным цветом. Полезно для отладки и UI элементов.
Прямоугольник
Рисует прямоугольник с возможностью заливки. Можно использовать для фонов, панелей и других элементов.
Треугольник
Рисует треугольник по трем точкам с возможностью заливки. Полезно для создания сложных форм.
Текст
Выводит текст на экран с указанными параметрами: позиция, размер, цвет. Поддерживает многострочный текст.
Изображение
Отображает изображение (спрайт) из редактора изображений в указанных координатах и размерах.
Очистить экран
Заливает весь экран указанным цветом. Обычно вызывается в начале каждого кадра для очистки предыдущего.

Анимация и эффекты

Анимация объекта
Настраивает анимацию спрайтов для объекта: список кадров, скорость проигрывания и зацикливание.
Создать частицы
Генерирует систему частиц с настраиваемыми параметрами: количество, цвет, размер, скорость, направление, время жизни.
Эффекты частиц
Предустановленные эффекты частиц: взрыв, огонь, дым, дождь, звезды, магия. Можно настроить основной цвет эффекта.
Очистить частицы
Удаляет все активные частицы с экрана. Полезно при смене уровней или рестарте игры.

Переменные

Глобальные переменные

Создать переменную
Объявляет новую глобальную переменную и присваивает ей начальное значение. Доступна из любого места программы.
Получить переменную
Возвращает значение ранее созданной переменной. Если переменной не существует, вернет undefined.
Изменить переменную
Устанавливает новое значение для существующей переменной. Можно использовать для счетчиков, флагов и других изменяемых данных.

Локальные переменные

Создать локальную
Создает переменную, привязанную к конкретному объекту. Доступна только внутри этого объекта через this.local.
Добавить к локальной
Увеличивает значение локальной переменной на указанную величину. Полезно для счетчиков внутри объектов.
Получить локальную
Возвращает значение локальной переменной объекта. Если переменная не существует, вернет undefined.

Процедуры

Функции

Создать процедуру
Определяет новую функцию с именем и набором параметров. Тело функции составляется из других блоков.
Вызвать процедуру
Выполняет ранее созданную функцию. Можно передать аргументы, соответствующие параметрам функции.
Параметры
Определяет параметры для функции. Каждый параметр имеет имя и может использоваться внутри функции.
Возврат значения
Завершает выполнение функции и возвращает указанное значение. Если не указан, функция вернет undefined.
↑ Наверх
